## Lab Title
Introduction to GitHub and C Programming Language

## Introduction
This lab introduces the basic concepts of GitHub and the C programming language. It provides hands-on practice with creating repositories, branches, commits, pull requests, and merging branches. It also introduces the basic structure and syntax of C programs.

## Objectives
1. Learn how to create and manage a GitHub repository.
2. Learn how to create branches and make commits.
3. Understand how to create and merge pull requests.
4. Learn the basic structure and syntax of C programs.
5. Develop basic problem-solving skills using C programming.

## C Programming Topics
- Basic structure of a C program
- Input and output
- Variables
- Data types
- Format specifiers
- Escape sequences
- Precision
